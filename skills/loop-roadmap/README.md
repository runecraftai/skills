# loop-roadmap

Type-aware roadmap generation from an idea or validation of an existing roadmap. Loads project-type guides to adapt interview rigor, then produces a `.flywheel/roadmap.md` + `.flywheel/state.md` ready for the loop engine.

| Field | Value |
|-------|-------|
| Version | 1.0.0 |
| Trigger | `/loop-roadmap`, "create a roadmap", "generate roadmap", "what should I build" |
| PT trigger | `/loop-roadmap`, "criar roadmap", "gerar roadmap" |

**Do not use for** pure information requests, mechanical operations, or when the user already has a fully-loaded roadmap and only needs execution (use `/loop-run`).

See [SKILL.md](SKILL.md) for the full process.
