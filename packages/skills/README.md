# Grimoire

[![npm](https://img.shields.io/npm/v/@runecraft/grimoire)](https://www.npmjs.com/package/@runecraft/grimoire)

A curated `SKILL.md` catalog and safe installer for coding agents. Choose skills by category, detect project recommendations, and install them for Pi, Claude Code, Codex CLI, or OpenCode.

```bash
npx @runecraft/grimoire
# or
bunx @runecraft/grimoire
```

The executable is `grimoire`:

```bash
grimoire list
grimoire detect
grimoire install -s spec-driven -t pi
```

Run `grimoire --help` for all options. See the [project README](https://github.com/runecraftai/skills#readme) for the catalog and workflow overview.
